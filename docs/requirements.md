# Требования первой версии

## Подтверждено владельцем
- Название: ПромтМаркет.
- Отдельный проект вне SnowForce.
- Продавец находится в России, покупатели из России, валюта RUB.
- Сейчас бизнес не оформлен; планируется регистрация ИП.
- Начать разработку проекта.
- Желаемые способы оплаты: СБП и криптовалюта.

## Границы реализации оплаты
Для российского магазина планируем СБП. Криптовалютная оплата не включена из-за ограничений на оплату товаров цифровой валютой в России. Реальное подключение СБП требует оформления отношений с провайдером; до подключения используются только тестовые операции. Платёжный провайдер пока не выбран.

## MVP
- Публичный каталог, поиск, категории и карточки товаров.
- Регистрация, вход, подтверждение email, восстановление пароля.
- Прямая покупка одного промпта.
- Серверное подтверждение оплаты и выдача доступа.
- Личная библиотека: просмотр, копирование и TXT.
- Административное управление товарами, заказами и платежами.

## Начальный каталог
1. Senior Python Developer — Программирование.
2. Бизнес-план за 30 минут — Бизнес.
3. Маркетолог уровня PRO — Маркетинг.

5. AI Image Prompt Architect — Генерация изображений.
6. AI Video Director — Генерация видео.

Последние два товара предназначены для текстового помощника, составляющего инструкции для генераторов. Совместимость не считается проверенной.
Полные тексты предоставлены владельцем в приложении чата; не включать их в публичные frontend-данные.

## Требует согласования
- Цены шести товаров.
- Правила лицензии, возвратов и доступа к будущим обновлениям.
