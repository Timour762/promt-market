# Готовность ПромтМаркета, 16.10.2026

## Реализовано и проверено локально
Новый дизайн внедрён, реальные товары сохранены; публичные примеры и ограничения добавлены. Текущие цены сохранены по прямому указанию владельца. Регистрация/авторизация/админка/заказы/библиотека/версии/закрытые тексты работают на существующей архитектуре. SMTP-адаптер и worker готовы, не включены без credentials. Webhook Сбера подготовлен для тестовой среды; реальная оплата отложена. Документы и deployment-конфигурация созданы как заготовки, внешнее размещение не выполнялось.

## Проверки окончательного кода
- `python -m unittest tests.test_security -v`: 6/6 passed. Изолированные временные схемы PostgreSQL, банковские ответы и SMTP подменены. Покрыты скрытый текст публичного каталога, CSRF/Origin, роль customer и запрет подмены роли, сброс пароля/отзыв сеансов/повторный токен, изоляция чужого заказа/TXT, повторное оформление и снимок цены/версии, повторные конкурентные webhook, несовпадение суммы и обнаруженный возврат, TLS SMTP, отклонение неподписанного клиента и раздельные лимиты клиентов.
- `npm run test:e2e`: 4/4 passed, desktop Chromium и мобильная эмуляция iPhone 13 в Chromium. Поиск, категории, пустая выдача/сброс, переход и перезагрузка товара, изображения, публичные страницы, поля входа, переход клавиатурой, ширина страницы, перенаправление анонима из библиотеки. Это не проверка Safari или настоящих устройств и не полный сценарий аутентифицированной админки в браузере.
- `npm run build`: exit 0, production output .next-release; TypeScript/build checks прошли. Осталось предупреждение autoprefixer о start/flex-start; оно не блокирует сборку.
- `npm audit` после обновления PostCSS до 8.5.30: 0 известных уязвимостей. Major Next.js не менялся.
- Исправлен реальный мобильный дефект: полоса категорий растягивала grid-элемент за экран. Добавлены min-width:0 и ограниченный внутренний scroll.
- Исправлены полностью буферизуемое тело auth-запроса, общий proxy-IP limiter, отсутствие readiness контейнеров. API/web порты production не публикуются; доверенный клиент передаётся с HMAC. Limiter рассчитан на один процесс API; для реплик нужен общий backend.

## Что пока не проверено и не подключено
Нет фактической отправки через Mail.ru, тестовых или реальных банковских операций, внешней доставки callback, Docker/server run, TLS/DNS, восстановления реальной резервной копии, нагрузочного прогона, реального прогона продаваемых инструкций на AI-моделях. Docker не установлен в текущем окружении. Юридические документы не утверждены и не являются готовой офертой. Подписки, цены, хостинг и домен не покупались.

## Остаток, требующий владельца
SMTP-пароль приложения для promtmarket@mail.ru (ввод локально через configure_mail.py), домен, российский сервер, полные реквизиты/адрес/налоговый статус и юридическое согласование. Текущие цены не менять. Инструкции: launch-requirements.md, deployment.md. После получения ресурсов нужны отдельная проверка внешних подключений и разрешение на публикацию. Задачу публичного запуска пока не закрывать.
