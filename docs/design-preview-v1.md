# Визуальный макет v1

2026-10-14. /design-preview. Изолированная страница на учебных данных, без API/БД/платежей. Новая типографика Onest с локальным шрифтом и лицензией, графит/кобальт, компактная навигация, боковые направления, поиск, фотообложки без тяжёлых рамок, крупный заголовок и отдельное представление товара. Макет нацелен на человека, который днём выбирает рабочую инструкцию с ноутбука или телефона. Существующие фотоматериалы переиспользованы; дополнительные генерации макетов не нужны, поскольку результат проверяется на живом localhost.

Взаимодействия: фильтр категорий, поиск, пустая выдача, очистка, переход в подробности товара/назад, сброс всех изменений. Аккаунт и заказ явно обозначены демонстрационными. Исходный каталог, главная, права и оплаты не менялись. Шрифт из google/fonts ofl/onest, SIL OFL в public/fonts/Onest-OFL.txt.

Проверки не запускались — FAST DEV. Требуется просмотр владельцем и явная команда внедрить этот макет. Commit/push не выполнялись.
