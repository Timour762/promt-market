# Материалы карточек товаров

2026-10-15. Для шести исходных ID добавлены публичные редакционные пояснения: аудитория, ожидаемый состав результата, пример исходной задачи и структуры ответа, сценарий использования и ограничения. Данные хранятся в frontend/src/lib/prompt-guides.ts, выводятся PromptGuide только при известном ID. Новые товары не получают случайно чужой пример. Текущие названия, описания, цены и защищённые версии в БД не менялись.

Примеры написаны отдельно, не скопированы из закрытых текстов. Подписаны как иллюстрации, а не проверенные ответы AI. ChatGPT, Claude и Gemini обозначены только примерами текстовых помощников: совместимость конкретной инструкции не заявлена. Для image/video выделено двухэтапное применение: текстовое задание, затем отдельный генератор. Подписка/генерация не включены в товар. Финансовые, рекламные и технические обещания отсутствуют.

Сведения о текстовом вводе/коде/написании проверялись по официальным материалам:
- https://help.openai.com/en/articles/20001246-working-with-writing-blocks-and-code-blocks-in-chatgpt
- https://support.anthropic.com/en/articles/11145838-using-claude-code-with-your-pro-or-max-plan
- https://gemini.google.com/gem/writing-editor

Остаток: ручная оценка каждого полного промпта на выбранных моделях, согласование цен остальных товаров; при расширении каталога перенести редакционные сведения в управляемую модель вместо ID-словаря. Реальные API моделей не вызывались. Проверки приложения не запускались — FAST DEV. Commit/push не выполнялись.
