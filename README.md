# ПромтМаркет

Отдельный магазин AI-промптов для покупателей из России. Цены в рублях.

## Текущий этап
Основа проекта и требования. Приложение пока не реализовано и не запущено.

## Планируемый стек
- Backend: Python, FastAPI, PostgreSQL, SQLAlchemy Async, Alembic.
- Frontend: Next.js, TypeScript, Tailwind CSS.
- Оплата: СБП через банк или платёжного провайдера, сначала тестовый режим.

## Структура
- docs — требования, решения, критерии приёмки.
- backend — будущий API и бизнес-логика.
- frontend — будущая витрина и административная панель.
- infra — будущая локальная и серверная инфраструктура.

Следующий шаг: согласовать первый экран витрины, затем реализовать изолированный локальный макет без реальных платежей.
