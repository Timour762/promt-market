# ПромтМаркет

Отдельный магазин AI-промптов для покупателей из России. Цены в рублях. Текущая версия предназначена для локального просмотра; реальный приём оплаты отложен.

## Реализовано
- Каталог, поиск, категории, шесть фотообложек и страницы товаров с редакционными примерами.
- Единый дизайн Onest, кабинет, библиотека, копирование текста и TXT.
- PostgreSQL/FastAPI/SQLAlchemy/Alembic; регистрация, вход, роли, подтверждение email и восстановление пароля.
- Административный редактор, версии текстов, учебные заказы, выдача доступа и аудит.
- Подготовка тестового эквайринга Сбера и webhook с серверной сверкой. Без внешнего подключения и реальных платежей.
- Доставка писем: локальные файлы или SMTP с TLS; SMTP требует отдельного пароля приложения.
- Черновики документов /legal/*, контакт promtmarket@mail.ru.
- Docker Compose для будущего сервера, TLS-прокси, healthchecks, резервное копирование и инструкции.

## Запуск и проверки
Локальные команды: [docs/local-development.md](docs/local-development.md).

Frontend: `npm ci`, `npm run dev` (порт 3107). Проверки: `npm run typecheck`, `npm run test:e2e`, `npm run build`. Сборка изолирована в .next-release.

Backend: создать .venv и частную .env, `pip install -r requirements.lock.txt`, `pip install -e .`, `python -m alembic upgrade head`, `python -m uvicorn app.main:app --host 127.0.0.1 --port 8107`.

API-тесты: `pip install -r requirements-dev.txt`, `python -m unittest tests.test_security -v` из backend. Тесты создают отдельные временные схемы PostgreSQL; аккаунты и заказы приложения не используются. Банковские запросы и SMTP подменяются учебными ответами.

## До публичного запуска
[Недостающие данные](docs/launch-requirements.md), [размещение](docs/deployment.md), [письма](docs/email-recovery.md), [уведомления Сбера](docs/sber-webhooks.md).

Нужны домен/сервер, SMTP-пароль приложения, полные сведения о продавце, окончательные документы и проверка размещения. Docker, внешняя доставка почты и реальные платежи не проверены. Неприсвоенные цены сохранены по указанию владельца. Не переносить локальный пароль администратора в production.
